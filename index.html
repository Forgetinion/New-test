Setting up Google Sheets sync

1. Go to console.cloud.google.com and create a project.

2. APIs & Services → Library → enable "Google Sheets API".

3. APIs & Services → OAuth consent screen → set it up (External, add your own email as a test user).

4. APIs & Services → Credentials → Create Credentials → OAuth client ID → type "Web application".

5. Under "Authorized JavaScript origins" add the exact URL this app is hosted at (e.g. https://yourname.github.io).

6. Copy the Client ID it gives you and paste it into Settings here.

This step only needs doing once. It's required because Google needs to know which site is allowed to ask for permission to read/write your Sheets.
